# Dashboard Logsheet

Dashboard interaktif offline dari data Logsheet (sheet "Mapping").

- `Dashboard_Logsheet.html`: dashboard offline, buka langsung di browser (semua aset sudah inline).
- `index.html`: template dashboard.
- `build_offline.py`: membangun file offline dari template dan data.
- `flip.py`, `kat2.py`: skrip bantu pengolahan data (pembalikan tanda P/Q, kategori).
- `preview_*.png`: tangkapan layar dashboard.
